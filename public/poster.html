1. SYSTEM REQUIREMENTS
1.1 Project Overview

The Proteam Gym web application is a full-stack gym management system built for Proteam Fitness, Vesu, Surat. It provides a complete digital platform for managing gym members, class schedules, membership plans, and bookings online. The Admin manages members and assigns plans, while Members can register, log in, book classes, and track their fitness journey. The system uses a secure REST API with JWT authentication and a file-based SQLite database requiring no external installation.

1.2 Key Web Features
User Login / Register:Secure sign-up & login with JWT token sessions; role-based access for Admin vs Member.
Membership Plans:Basic (₹999/mo), Standard (₹2,499/3mo), Premium (₹7,999/yr). Admin assigns plans from dashboard.
Class Booking:12 weekly classes (Mon–Sun) with live capacity tracking. Booking blocked automatically when full.
Admin Panel:Full member management — view, assign membership, view bookings & contact messages.
Member Dashboard:View profile, active membership, booked classes, expiry date, and BMI calculator tool.
Trainers Page:4 certified trainer profiles with specialization, experience, bio, rating, and Instagram handle.
Contact Form:Inquiry form saved to database. Admin can view, mark as read, or delete messages.
DB Viewer:Browser-based admin database viewer — view all 6 tables, search, and delete records live.
Gallery & Images:Real Proteam Fitness photos (reception, equipment, floor) in mosaic grid on home page.
Responsive Design:Mobile-friendly layout using CSS Grid & Flexbox; works on phones, tablets, and desktops.
1.3 Non-Functional Requirements (NFR)
Security:Passwords hashed with bcrypt; JWT tokens for sessions; admin routes protected with role middleware.
Usability:Simple, clean interface with smooth animations; dark theme; accessible for all fitness levels.
Performance:SQLite WAL mode for fast reads; lightweight Express server; all API responses under 100ms.
Reliability:Foreign key constraints enforced; booking count cannot exceed class capacity; data stays consistent.
Scalability:SQLite supports up to 281 TB of data; architecture ready for MySQL/PostgreSQL migration.
Portability:Single `.db` file; runs on Windows/Linux/Mac with Node.js — no server or DB installation needed.

2.2 Architecture Diagram

The application follows a client–server model. The user interacts with the website in a browser; JavaScript sends HTTP requests to the Express.js server; the server validates JWT tokens, applies business logic, and queries the SQLite database, then returns JSON responses rendered by the frontend.

2.4 Server-Side Technologies

This project uses Node.js as the server-side runtime with Express.js as the web framework to handle routing and API requests. Server-side scripting — similar to how PHP handles backend logic in traditional web projects — is managed through Express.js route handlers that process requests, validate JWT tokens, and interact with the SQLite database before returning a JSON response to the client.

4. CONCLUSION
The Proteam Gym project successfully implements full-stack web development using a Node.js + Express.js + SQLite architecture. It features JWT-based authentication with role-based access control for Members and Admins, bcrypt-encrypted password storage following security best practices, and a complete REST API with 15+ endpoints handling all server-side business logic.

The frontend delivers a fully responsive, mobile-friendly experience with a class booking system that enforces real-time capacity limits, a member dashboard for self-service, and an admin panel for complete gym management. Real photos of Proteam Fitness gym in Vesu, Surat are integrated across the site. A custom browser-based DB Viewer allows live data inspection and deletion without any external tools. The modular design makes it straightforward to extend with payment gateway integration, SMS notifications, or cloud deployment in future iterations.
